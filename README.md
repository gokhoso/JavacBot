# Configuration
**You must change Placeholder values first.** <br/>
The bot has a feature called config variables. This feature is designed for customization. <br/>
### Usage Of Variables in config.yml: <br/>
Small Note: Member variable is only available for Systems.<br/>
```
{guild.name} -> Guild's username.
{guild.iconUrl} -> Guild's profile photo.
{bot.name} -> Bot's username.
{count} -> Number of guild members.
{count.ordinal_suffix} -> Number of guild members with suffix.
{member.name} -> System's event member. (For example, GuildMemberJoinEvent gives us an event.member and MessageReceivedEvent also gives us an event.member)
{member.mention} -> Performs the same  function as {member.name} but mentions member.
```
